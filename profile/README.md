# Arcela Technologies

We design and build software, and the circuit boards it runs on when a project needs them.

Every project starts from a written specification, so you know exactly what is being built, what isn't, and how it will be handed over before any work begins.

## What we build

- **Screens:** web apps, client portals and mobile apps
- **Services:** accounts, data, billing and the systems behind them
- **Connections:** payments, email, phone lines and accounts packages
- **Devices:** bespoke ESP32 and STM32-based circuit boards and firmware

## How a project runs

1. **Conversation.** We look at the problem, the people involved and the tools already in use.
2. **Specification.** A short written summary of what will be built, with a quote.
3. **Build.** Working versions arrive as the system takes shape, and changes are discussed against the specification.
4. **Handover.** We set the system up, move across the data it needs, and train the people who will use it.

## What holds on every project

- Nothing is designed or built until you have agreed, in writing, what is being made.
- You deal with one person from the first conversation to support after launch.
- The design is documented at handover, so someone else could understand the system and run it.
